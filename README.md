# dyauto
A C++-based CTP quantitative trading system

介绍
基于上期所ctp系统架构设计的C++期货程序化交易系统。我们制作的这个C++量化平台名叫鼎元C++全自动交易系统。它属于国内最近几年兴起的“自编程序化”的一种。最近几年随着国内期货程序化盛行，特别是上期所推出上期ctp技术标准化接口后，很多人使用各种平台进行期货程序化系统搭建，主要有C++语言系统平台、python系统平台以及其它一些语言的系统平台，现在国内主要是C语言和Python两种语言为最多。

鼎元C++程序化系统是基于CTP技术用C++语言写的集交易，行情，策略设计于一体的一个程序化交易解决方案。PT组合交易，Tick/Bar双模式并行，多账户多合约多周期均无障碍交易。使用办法：按需要下载到本地电脑，解压鼎元软件双击打开，输入会员名和密码（公开测试账号：test01,test02,test03,test04,test05.密码：111111）登录即可体验完全自动化交易的魅力！】
