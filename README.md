# 软件架构

（1）、数据下载器（数据下载软件） 通过CTP系统自动下载交易所tick数据,然后软件自动生成各种周期的bar数据供鼎元软件使用。

（2）、鼎元程序化软件（程序化软件） 内置tick与bar数据，同时模块化交易各种接口，鼎元界面配置策略及自动交易。

（3）、程序化策略模板（策略设计源码模板） 通过模块化处理各种接口形成策略模板，程序化人员即可通过调用这些接口实现程序化交易的各种复杂策略。

鼎元全自动交易系统主要分三部分，一部分是模块化的各种接口形成的软件实体。二是数据下载器（非必要，数据已经内置到鼎元软件里面）。三是各种策略与接口使用与调的源码模板。

通过模板设计各种策略然后形成C++的DLL文档。加载到鼎元软件里面，配置好软件即可形成全自动交易系统。

鼎元C++程序化主要分两个部分，一个是策略编写部分【策略模块】，二是程序化环境配置和运行策略部分【交易模块】。

# 【策略模块】

就是策略程式码部分，交易思路大脑，都是程式码，呈现以DLL格式，将C++语言的策略转换成DLL文件加载到交易模块里面。策略编写我们推荐使用VS2019旗舰版。

【交易模块】 就是将写的交易策略应用到交易中的模块，这里面也分成两类，一个是环境设置，包括交易品种，交易周期，期货账户以及其它一些辅助类的功能。二是策略参数设置，包括程序化策略各变量的参数属性，以及与策略相关的一些必要设置。
